# JUST TODAY

내일 걱정 말고, 오늘만 하자. 윈도우 화면 맨 위에 늘 떠 있는 할 일 · 뽀모도로 · 하루 기록 위젯 · 만든 사람 겨울작가 (AI 수익화 전문) · https://theaiwk.com

**[JUST TODAY 최신 버전 받기](https://github.com/youri355/justtoday/releases/latest)** → 페이지 아래 Assets에서 `JustToday_버전.zip`

## 처음 실행하는 법
1. 받은 압축파일을 오른쪽 버튼 → **[모두 압축 풀기]**
2. 풀린 JustToday 폴더를 문서 폴더처럼 지우지 않을 곳에 두기 (다운로드 폴더는 X)
3. 폴더 안의 **JustToday.exe** 두 번 누르기 (파일 끝 글자가 숨겨진 PC에서는 "JustToday"로 보여요. 종류가 "응용 프로그램"인 것)
4. 파란 창 "Windows의 PC 보호"가 뜨면 **[추가 정보] → [실행]** (처음 한 번만)
5. 설정(톱니바퀴) → 기타 → **[윈도우 켤 때 자동 실행]** 체크, **[바로가기 다시 만들기]**

## 새 버전
새 버전이 나오면 프로그램이 "새 버전이 나왔어요" 창을 띄워요. **[지금 업데이트]** 를 누르면 알아서 받아서 바꾸고 다시 켜져요. 할 일 · 기록 · 메모는 그대로 남아요.
